## 3. Bucket Definitions

Bucket M1 - Pure entity extraction:

- LPCHARACTER is used only to call `AIHelpers::EcsOf(ch)` or equivalent.
- Migration: change signature to `entt::entity`.
- Risk: low.

Bucket M2 - Service-call bridge:

- Function needs legacy service operations such as packets, descriptors, sectree, DB save, event callbacks or item service objects.
- Migration: public API can become `entt::entity`, but implementation may use `LegacyCharOf` as a write/service bridge.
- Risk: medium.

Bucket M3 - Heavy legacy-bound:

- Function is a legacy class method body or deeply mutates/depends on CHARACTER internals.
- Migration requires subsystem refactor, not a mechanical signature pass.
- Risk: high.
