Phase 15E-final.1f - CItem Packet Body Cleanup + Virtual Dispatch Refactor

Scope
- Kept the `CItem::` virtual packet override bodies because `LPENTITY`/`entity_view` still dispatches through that protocol.
- Rewrote the body content into thin ECS-resolving wrappers.
- Added native ECS item packet builders under `ecs::ItemNetworkSystem`.
- Added `ecs::EntityFromLPENTITY` as a narrow virtual-dispatch boundary helper.

Virtual bodies migrated
- `CItem::EncodeInsertPacket(LPENTITY)`
- `CItem::EncodeRemovePacket(LPENTITY)`
- `CItem::UpdatePacket()`
- `CItem::UsePacketEncode(LPCHARACTER, LPCHARACTER, packet_item_use*)`

ECS components added
- `ItemGroundPosition`: ground packet x/y/z.
- `ItemOwnershipDisplay`: owner name shown on protected ground drops.
- `ItemLockedAttribute`: `ATTR_LOCK` packet field.

Sync coverage added
- `EntityFactory::SyncItemEntity` populates `ItemGroundPosition` and `ItemLockedAttribute`.
- `CItem::AddToGround` syncs `ItemGroundPosition`.
- `CItem::RemoveFromGround` clears `ItemGroundPosition`.
- `CItem::SetOwnership` syncs/clears `ItemOwnershipDisplay`.
- `CItem::SetLockedAttr` syncs `ItemLockedAttribute`.

Hotfix: ground item insert ordering
- Symptom: dropping an item removed it from inventory, but the ground item did not appear and then looked immediately deleted.
- Cause: `CItem::AddToGround` updated `ItemGroundPosition` after `tree->InsertEntity(this)` / `UpdateSectree()`. The native `CItem::EncodeInsertPacket` can be dispatched during sectree insert, so the packet builder saw no `ItemGroundPosition` and skipped the ground-add packet.
- Fix: hydrate the item ECS entity and write `ItemGroundPosition`, `ItemLocation`, owner/equipped state before sectree insertion. Ground insert packets now have the ECS state available at dispatch time.

Native packet builders
- `EncodeItemGroundInsert`: reads `ItemIdentity + ItemGroundPosition`.
- `EncodeItemGroundRemove`: reads `ItemIdentity`.
- `EncodeItemUpdate`: reads `ItemLocation + ItemCount + ItemSockets + ItemAttributes + ItemLockedAttribute`.
- `EncodeItemUse`: reads `ItemIdentity + ItemLocation` and entity packet VIDs.
- `SendItemInsert`, `SendItemRemove`, `SendItemUpdate`: send through `NetworkService`.

Boundary decision
- Chosen approach: hybrid/minimum-invasive virtual wrapper.
- The virtual `CItem::` overrides remain because `entity_view` and sectree view insertion still call polymorphic `LPENTITY::EncodeInsertPacket/EncodeRemovePacket`.
- The wrappers now only resolve ECS entities and delegate packet construction/sending to ECS systems.
