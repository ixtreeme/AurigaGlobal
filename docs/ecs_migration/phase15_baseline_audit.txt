- questlua mass migration pattern sweep
- unify PC/NPC entity lookup helpers
- low-risk LPCHARACTER parameter replacements in Lua bindings and helper utilities

- EASY-tier files (<10 usages)

- expect bridge-heavy intermediate state

- EPIC-tier files (150+)
- input_main.cpp, char_manager.cpp, other core dispatch/runtime files
- this is the critical-path risk window

Week 11
- collapse remaining direct CHARACTER data access behind thin wrappers / ECS bridge helpers
- remove broad char.h dependency where still possible

Week 12
- stabilization, regression-fix budget, final LPCHARACTER sweep, prep for next ECS/storage phase

Feasibility assessment
- Three months is aggressive but plausible only if migration stays pattern-driven, questlua is bulk-converted early, and EPIC files are split into narrow bridge phases. It is not realistic as a pure manual one-file-at-a-time rewrite.
- The most fragile risk zone is the EPIC set: high fanout runtime / input / manager files where LPCHARACTER variables, parameters, and chained method calls all coexist.
