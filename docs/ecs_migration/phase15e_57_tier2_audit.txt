5. Already-migrated patterns and ECS availability

- ChatPacket: caller-side complete; use ecs::ChatSystem.
- PointChange: caller-side complete for writes; PointSystem::Change bridges legacy routing. Read side (`GetPoint`, `GetRealPoint`, `GetGold`) remains a major Tier 2 target and must respect the 15C-1j points[] semantic split.
- Quest flags: caller-side complete; use ecs::QuestSystem::GetFlag/SetFlag.
- Party/Guild: caller-side complete; service object return types remain LPPARTY/CGuild*.
- Affect add/remove: caller-side complete; affect read queries (`FindAffect`, `IsAffectFlag`) remain next-tier candidates.
- GetDesc: caller-side CHARACTER access complete; DESC remains infrastructure pointer. LPENTITY->GetDesc paths are intentionally out of scope.
- Identity components exist: ecs::PlayerID, ecs::PlayerName, ecs::EmpireComponent, ecs::RaceComponent, ecs::GMLevel, ecs::VIDComponent, TagPC/TagNPC/TagMonster/TagStone.
- Position components exist: ecs::Position and ecs::MapIndex, plus SectorPlacement. Adoption is partial; `GetMapIndex/GetX/GetY/GetSectree` remain heavily used.
- Vital/stat components exist: ecs::LevelComponent, Health/Mana components, CharacterStatsComponent. Adoption is partial and point reads remain hybrid.
- Inventory/item accessors exist from 15E item phases: GetWearItem, GetItemCount/Vnum/etc., AutoGiveItemEcs. `GetWear/GetInventoryItem/GetItem/CountSpecifyItem/RemoveSpecifyItem` remain a separate item/inventory accessor batch.

6. Recommended next phases

Phase 15E-58: Character identity/type read accessors
- Target methods: GetPlayerID, GetName, GetEmpire, GetGMLevel, GetPacketVID, IsPC, IsNPC, IsMonster/IsStone where present.
- Combined tracked count estimate: GetPlayerID 148, GetName 174, GetEmpire 45, GetGMLevel 37, GetPacketVID 31, IsPC 138, IsNPC 16, IsStone 18 = about 607 tracked calls before broader aliases.
- Risk: Easy/Medium. Mostly read-only. Main caution is `GetName()` lifetime and type predicate false positives.
- Approach: add/verify `ecs::CharacterSystem` or `PlayerRuntime` identity accessors, then migrate in file batches. Keep `const char*` compatibility wrapper if needed.

Phase 15E-59: Position/map read accessors
- Target methods: GetMapIndex, GetX, GetY, GetSectree, possibly GetXYZ-style helpers.
- Combined tracked count estimate: GetMapIndex 128, GetX 63, GetY 42+ from alias scan, GetSectree 17 = about 250+ tracked calls.
- Risk: Medium. Reads are simple but map/sector/teleport code is sensitive; do not mutate movement here.
- Approach: add `MovementSystem::GetMapIndex/GetX/GetY/GetPosition/GetSectree` entity-first reads, migrate read-only callers, leave `WarpSet/Show/OnMove` for a write phase.

Phase 15E-60: Point/stat and affect read accessors
- Target methods: GetPoint, GetRealPoint, GetGold, GetMaxHP, GetMaxSP, GetLevel, FindAffect, IsAffectFlag.
- Combined tracked count estimate: GetPoint 221, GetRealPoint 22, GetGold 52, GetMaxHP 24, GetMaxSP 16, GetLevel 58, FindAffect 34, IsAffectFlag 37 = about 464 tracked calls.
- Risk: Medium/High. Point read semantics must follow the 15C-1j split: true stat-array vs virtual/live vs computed.
- Approach: first add read-only `PointSystem::Get/Real/GetGold/GetMaxHP/GetMaxSP/GetLevel` wrappers that delegate to legacy routing; only later move storage authority. Add `AffectSystem::HasFlag/Find` wrappers for affect reads.
