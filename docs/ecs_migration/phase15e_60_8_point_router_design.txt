# Phase 15E-60.8 POINT Router Design

Date: 2026-05-02
Scope: PointSystem::Get / GetReal semantic routing audit.

## Enum Range

POINT_MAX_NUM is 255 from SRC/Server/common/length.h.

## Legacy Routing Baseline

CHARACTER::GetPoint(uint8_t type):
- Bounds-checks type against POINT_MAX_NUM.
- Reads m_pointsInstant.points[type].
- Applies only overflow diagnostics for POINT_STEAL_HP, POINT_STEAL_SP, POINT_GOLD.
- Returns the instant/live value.

CHARACTER::GetRealPoint(uint8_t type):
- Reads m_points.points[type].
- Returns the real/base value.

This means the safe ECS equivalent is:
- Get(): dedicated live components for virtual points, otherwise CharacterStatsComponent.points[type].
- GetReal(): CharacterPoints.base.points[type] for real/base values, with dedicated component reads only where legacy semantics already make the value virtual.

## Dedicated / Virtual Sources

POINT_LEVEL -> SRC_LEVEL -> LevelComponent.value
POINT_HP -> SRC_HP_CURRENT -> Health.current
POINT_MAX_HP -> SRC_HP_MAX -> Health.max
POINT_SP -> SRC_SP_CURRENT -> Mana.current
POINT_MAX_SP -> SRC_SP_MAX -> Mana.max
POINT_STAMINA -> SRC_STAMINA_CURRENT -> Stamina.current
POINT_MAX_STAMINA -> SRC_STAMINA_MAX -> Stamina.max
POINT_GOLD -> SRC_GOLD -> GoldAmount.amount
POINT_EXP -> SRC_EXP -> Experience.current
POINT_NEXT_EXP -> SRC_NEXT_EXP_COMPUTED -> Experience.next when populated, otherwise exp_table[level]

## Array Sources

All non-dedicated stat points default to:
- Get(): SRC_INSTANT_ARRAY -> CharacterStatsComponent.points[type]
- GetReal(): SRC_REAL_ARRAY -> CharacterPoints.base.points[type]

This covers combat grades, base stats, resistances, bonuses, party bonuses, mall bonuses, skill/stat counters, playtime, polymorph, mount, energy, and feature-gated POINT_* values that are still backed by the legacy points arrays.

## Legacy-Only Transitional Sources

The following are deliberately marked SRC_LEGACY_ONLY because the current ECS component model does not yet expose an owning component:
- POINT_INVEN when __ENABLE_EXTEND_INVEN_SYSTEM__ is enabled.
- POINT_GAYA when ENABLE_GAYA_SYSTEM is enabled.

These must emit a one-time [POINT_LEGACY_ONLY] warning if read through PointSystem::Get/GetReal and remain candidates for 15E-60.9 component extension.

## Risk Notes

The router depends on write-side sync:
- SetPoint must mirror m_pointsInstant.points[type] into CharacterStatsComponent.points[type].
- SetRealPoint must mirror m_points.points[type] into CharacterPoints.base.points[type].
- Dedicated setters already mirror HP/SP/stamina/max values, level, exp, and gold into ECS components.

Without this sync, GetPoint would read stale ECS values and reproduce the previous stat drift class.
