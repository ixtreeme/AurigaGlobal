Priority fix list
1. Delete or quarantine CharacterAccessors.hpp LPCHARACTER surface.
   - Biggest fake surface: 700 calls.
   - Replace wrapper usage with explicit entity ownership in callers.

2. Attack non-ECS EcsOf(...) hotspots.
   - Biggest holders: cmd_gm.cpp, input_main.cpp, cmd_general.cpp, New_PetSystem.cpp, guild.cpp, char_manager.cpp.
   - These files still own LPCHARACTER and convert late.

3. Collapse questlua reverse bridges.
   - 345 wrong-direction LegacyCharOf(...) calls.
   - Passing entity into Lua glue is not enough if the glue immediately converts back to CHARACTER.

4. Remove the ItemSystem.hpp public LPCHARACTER backdoor.
   - Current fake public ECS API:
     - SyncExtraInventoryAll(LPCHARACTER ch)

5. Re-clean ECS internals with high LPCHARACTER counts.
   - CombatSystem.cpp
   - PlayerRuntimeSystem.cpp
   - ItemSystem.cpp
   - NetworkSyncSystem.cpp
   - MovementSystem.cpp

Bottom line
- Real migration exists: ChatSystem is clean, and recent system headers are mostly clean.
- The codebase still carries a larger fake surface than real surface when measured at actual usage sites.
- The main illusion is not public overloads anymore; it is transitional accessor sugar plus pervasive EcsOf(ch) and questlua LegacyCharOf bridges.
