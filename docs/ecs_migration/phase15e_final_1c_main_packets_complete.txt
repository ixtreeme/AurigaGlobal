Phase 15E-final.1c - MainCharacterPacket + UpdatePacket + PointsPacket native rewrite

Scope
- Rewrote the central self/update/stat packet paths behind entity-first NetworkSyncSystem APIs.
- Removed the legacy CHARACTER packet bodies after caller migration.
- Kept broadcast iteration as the documented service bridge until Phase 15E-final.1d.

Packets rewritten
- Main character packet:
  - NetworkSyncSystem::MainCharacterPacket(entt::entity)
  - Handles default BGM, BGM name, and BGM volume packet variants.
- Character update packet:
  - NetworkSyncSystem::BuildCharacterUpdatePacket
  - NetworkSyncSystem::UpdatePacket(entt::entity)
- Points packet:
  - NetworkSyncSystem::BuildPointsPacket
  - NetworkSyncSystem::PointsPacket(entt::entity)

ECS sources used
- VIDComponent: packet VID.
- PlayerName via PlayerRuntime::GetName.
- RaceState via PlayerRuntime::GetRaceNum.
- Position and MapIndex: spawn coordinates and BGM lookup.
- EmpireComponent via PlayerRuntime::GetEmpire.
- SkillLevels.group: main character skill group.
- AppearancePartsComponent: visible equipment parts.
- CombatStats: alignment and PK mode.
- AffectList.flags: visible affect flag bits.
- StatusFlags: dead, spawn, killer, party packet state bits.
- SocialRefs via SocialSystem: guild and party state.
- MountState via MountSystem::GetMountVnum.
- SkillColor: skill color payload.
- PointSystem::Get: full POINT_* packet values.
- NetworkSession via NetworkService: descriptor send and language.

Sync paths verified or added
- PK mode was already mirrored to CombatStats by 1b.
- Skill color was already mirrored to SkillColor by 1b.
- Added StatusFlags mirrors for killer, spawn, and party packet state.
- AffectSystem now syncs AffectList before native update packet sends from affect write paths.

CHARACTER bodies deleted
- CHARACTER::MainCharacterPacket
- CHARACTER::UpdatePacket
- CHARACTER::PointsPacket

char.h declarations removed
- MainCharacterPacket
- UpdatePacket
- PointsPacket
