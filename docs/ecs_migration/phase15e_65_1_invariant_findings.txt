## 3. Item Creation Path Audit

- `SRC/Server/GameServer/item_manager.cpp:258` uses `M2_NEW CItem(vnum)`.

Canonical hydration:

- `SRC/Server/GameServer/item_manager.cpp:527` calls `EntityFactory::CreateItemEntity(g_registry, item)` before returning from `ITEM_MANAGER::CreateItem`.
- `SRC/Server/GameServer/item_manager.cpp:408` also hydrates before an early blend-item return.

Conclusion:

- Runtime `[ITEM_BYPASS]` warnings are still required to confirm all legacy item instances with nonzero ID are linked to ECS during production paths.

## 5. Write Sync Risk Audit

Potential stale-state write clusters found:

- `item_manager.cpp:286-527`: item initialization writes sockets/count before the final factory hydration. This is acceptable if no ECS read happens before `CreateItemEntity`.
- `item_manager.cpp:1084,1112,1277,1314`: polymorph item socket writes after item creation. These need later sync verification.
- `item_manager.cpp:2080-2102`: accessory/refine socket copy writes. These need later sync verification.
- `ItemSystem_LegacyBridge.cpp`: many item creation/write paths remain intentional bridge territory and need a dedicated sync pass.

No write sync fixes were applied in this phase.
