3. Migration Patterns Established

Scalar getters:
- Caller-side ch->GetX() became ecs::PlayerRuntime::GetX(AIHelpers::EcsOf(ch)).

Type predicates:
- Tag check is attempted first.
- Legacy fallback is used when ECS tags are missing, preserving combat and skill behavior.
- This fallback was production-critical after the 15E-58b no-damage regression.

GetRaceNum:
- PlayerRuntime uses legacy CHARACTER::GetRaceNum first to preserve polymorph semantics.
- Component fallback remains available for non-legacy entities.

GetName:
- PlayerRuntime::GetName returns std::string_view.
- The view is backed by stable storage: PlayerName component storage or legacy CHARACTER name storage.
- Caller-side migration uses .data() where legacy APIs expect null-terminated const char*.
- This preserves ChatSystem::Send, snprintf, strlcpy, Lua, packet, and log call behavior.
